以后家的样子

不用一次想完。每个房间写一点想要的样子，心愿清单想到什么加什么 — 这是给未来的自己的小蓝图。

还差最后一步：数据库规则还没包含这个小角落，内容暂时存不进去。 打开 Firebase console → 项目 x-planner-99dd3 → Firestore Database → Rules，把规则换成下面这版再点 Publish，回来刷新就好了： 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /planners/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /xwei/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
